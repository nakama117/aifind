## SEO 与内容管理

后台入口为 `/admin/login`，使用私密 `.env` 中的 `ADMIN_PASSWORD`，无单独用户名。操作说明见 [中文手册](admin-and-seo-zh.md)。

已实现日文 title/description、canonical、`ja-JP`、Open Graph/X 卡片、JSON-LD、文章/报表分享图、robots、sitemap，以及 Google/Bing HTML 验证值配置。未到发布时间和撤稿的文章不会进入站点地图；后台、站内搜索、收藏和整站预览不收录。预览 HTML 及 API/RSS 等响应头均包含 noindex。

正式域名、DNS/TLS、Google/Bing 所有权验证和提交 sitemap 尚未执行。生产前必须将域名和联系信息换成实际值，完成试运行后再关闭 `SITE_PREVIEW`。全站标题和介绍在 `site/site.ts` 修改，后台 SEO 页目前提供状态检查；文章 SEO 随人工标题/摘要同步。
